# Contributing

DataEnd is built by one person right now, and the rows change weekly. Until v1.0.0 ships, pull requests aren't accepted. Issues and discussions are: if something is wrong, unclear, or missing, say so.

If you open a PR anyway, thank you. It'll get a reply. Either it's merged under the [CLA](CLA.md) with your name on it, or the idea is reimplemented with credit in the changelog.

This changes at v1.0.0. The rule will be written here when it does.
