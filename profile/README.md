# DataEnd

Your business in one database. Built for you and Claude.

DataEnd is open source, Apache 2.0. It started as the database behind [Prodx](https://prodx.com), where it helps power digital customer experiences for retailers and has served billions of requests. We're rebuilding it from the ground up, as a product, in the open.

**Where Things Are**

- [`dataend`](https://github.com/dataend-ai/dataend): the spec. Every table in the platform, as JSON rows. Rows change weekly until v1.0.0.
- [`dataend-website`](https://github.com/dataend-ai/dataend-website): [dataend.com](https://dataend.com).
- Runtime, app, and clients follow, in that order.

One person is building this right now. Issues and discussions are welcome; pull requests aren't accepted yet. Please see [CONTRIBUTING](https://github.com/dataend-ai/.github/blob/main/CONTRIBUTING.md).
